# Code of Conduct

## Our commitment

We want participation in this project to be a respectful, constructive, and welcoming experience for everyone, regardless of experience level, background, identity, or point of view.

## Expected behavior

Examples of behavior that helps create a positive environment include:

- Being respectful and considerate.
- Giving and accepting constructive feedback.
- Focusing criticism on ideas, code, and technical decisions rather than people.
- Acknowledging different levels of experience.
- Acting in the best interests of the project and its community.

## Unacceptable behavior

Examples include harassment, insults, discriminatory language, personal attacks, intimidation, unwanted sexual attention, and publishing another person's private information without permission.

## Maintainer responsibilities

Project maintainers are responsible for clarifying and enforcing these standards in project spaces. They may remove, edit, or reject contributions that violate this Code of Conduct and may temporarily or permanently restrict participation for repeated or serious violations.

## Reporting

Report unacceptable behavior privately to the project maintainer through the contact method listed on the GitHub repository profile. Do not include sensitive personal information in a public issue.

## Scope

This Code of Conduct applies in project spaces, including Issues, Pull Requests, discussions, and other community interactions associated with the project.

## Attribution

This document is a concise project-specific code of conduct. The maintainers may revise it as the community and project needs evolve.
